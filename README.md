# Hibiscus — site statique

Structure :

- `index.html` : contenu du site
- `assets/css/style.css` : toute la mise en forme
- `assets/images/` : images utilisées par le site

Pour modifier le texte, ouvre `index.html`.
Pour modifier couleurs, tailles, espacements ou responsive, ouvre `assets/css/style.css`.

## Mise en ligne avec GitHub Pages

1. Crée un dépôt GitHub public.
2. Dépose tout le contenu de ce dossier à la racine du dépôt.
3. Dans GitHub : Settings > Pages.
4. Dans Build and deployment, choisis `Deploy from a branch`.
5. Sélectionne la branche `main`, puis le dossier `/(root)`.
6. Enregistre.

Le fichier `index.html` doit rester à la racine si tu publies depuis `/(root)`.
